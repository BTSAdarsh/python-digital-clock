# Digital Clock - PyQt5 Application

A simple digital clock application built with Python and PyQt5.

## Features

- Real-time digital clock display
- Clean, minimal UI with green text on black background
- Updates every second
- 12-hour format with AM/PM indicator

## Requirements

- Python 3.x
- PyQt5

Install dependencies:
```bash
pip install PyQt5
```

## Usage

Run the application:
```bash
python digital_clock.py
```

## Preview

The clock displays time in `hh:mm:ss:AP` format (e.g., `03:45:22:PM`) with a large green font on a black background.
